## Agent skills

### Issue tracker

Issues live in GitHub Issues for this repo (via `gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout. See `docs/agents/domain.md`.

### Thesis

The graduation thesis is written in Vietnamese Markdown under `docs/thesis/`. Before writing, editing, or reviewing any thesis content, read `docs/thesis/THESIS_STRUCTURE.md` — the university's formatting rules (EPU). They override the generic chapter layout in the `thesis-writing` skill.
